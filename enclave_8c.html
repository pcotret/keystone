Detailed Description

Enclave management and context switching for the Keystone Security Monitor.

This file implements core logic for enclave lifecycle management including:

  • Metadata initialization
  • Enclave creation and destruction
  • Context switching to and from enclaves
  • PMP region management
  • Memory cleanup and validation
