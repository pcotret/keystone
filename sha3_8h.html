Detailed Description

SHA-3 (Keccak) cryptographic hash function interface.

This header defines an implementation of the SHA-3 (Keccak) cryptographic hash functions, including initialization, update, and finalization routines. It also includes a direct hash interface for computing hashes in a single call.
