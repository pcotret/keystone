◆ sbi_trap_handler_keystone_enclave()

void sbi_trap_handler_keystone_enclave ( struct sbi_trap_regs *  regs)

Trap handler for enclave-related SBI calls.

Parameters
regsPointer to trap registers.

Handle trap/interrupt

This function is called by firmware linked to OpenSBI library for handling trap/interrupt. It expects the following:

  1. The 'mscratch' CSR is pointing to sbi_scratch of current HART
  2. The 'mcause' CSR is having exception/interrupt cause
  3. The 'mtval' CSR is having additional trap information
  4. The 'mtval2' CSR is having additional trap information
  5. The 'mtinst' CSR is having decoded trap instruction
  6. Stack pointer (SP) is setup for current HART
  7. Interrupts are disabled in MSTATUS CSR
Parameters
regspointer to register state
