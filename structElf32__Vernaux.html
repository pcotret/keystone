Detailed Description

ELF32 Version Needed Auxiliary Entry.

ELF64 Version Needed Auxiliary Entry.

Represents an auxiliary entry in the version needed section of an ELF32 file. This entry contains versioning information required for a symbol, including the hash of the version, flags, and the name of the version.

Represents an auxiliary entry in the version needed section of an ELF64 file. This entry contains versioning information required for a symbol, including the hash of the version, flags, and the name of the version.
